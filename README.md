# py-hello-worlds
Projek ini adalah projek sederhana yang akan menunjukkan berbagai cara menampilkan "Hello world" di Python.

## Original
sintaks `print("Hello World")`. Sederhana, langsung muncul.

## Function
sintaks:  
```python
def function():
    print("Hello world")

def fungsi():
    return "Hello world"
```
